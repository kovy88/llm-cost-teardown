## 1. Purpose

The Client may share aggregate LLM usage and cost exports, optional fingerprinted request logs, and eval queries so the Auditor can produce a savings estimate or a paid audit.

## 2. Confidential information

Includes the exports, logs, eval items, invoices, and anything marked confidential. Aggregate numbers in the report that cannot identify the Client or its customers are not confidential once the Client accepts the report.

Prompt and response text are not required. If the Client sends any, it is confidential and the Auditor will not copy it into the report, a repository, or a third-party tool except the model APIs the Client agrees to use for the eval.

## 3. Use and care

The Auditor uses the data only for this engagement, stores it outside shared or public repositories (`data/private/` locally, gitignored), and deletes it when the engagement ends or earlier on written request (within 7 days).

The Auditor does not receive API keys or access to the Client's accounts.

## 4. Non-disclosure

Neither party discloses confidential information to third parties except professional advisers under a duty of confidence, or as required by law (with notice where legal).

## 5. Term

Obligations last 3 years from the date of this NDA. Return or deletion of data is due when the engagement ends.

## 6. No licence, no warranty

Sharing data grants no licence to the Client's product or models. Data is provided as-is.
