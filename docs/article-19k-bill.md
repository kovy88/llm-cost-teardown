# Where a $19k/month LLM bill goes (and how 48 % of it is not load-bearing)

_Numbers below are from a synthetic company, Acme Helpdesk AI: 7 features, OpenAI + Anthropic, 30 days of usage. Generated by the open-source analyzer in this repo. Re-run it: `uv run llm-cost-teardown samples && uv run llm-cost-teardown analyze data/samples/*.json data/samples/requests.jsonl --eval-set data/samples/eval_set.jsonl --eval-baseline data/samples/eval_baseline.jsonl --eval-candidate data/samples/eval_candidate.jsonl --report report.md`._

Acme spends **$19,114 / month**. The analyzer's stacked (not summed) base saving is **$9,217 / month**, about **48 %**. Conservative to optimistic: $5.5k–$11.4k. The three lines that matter:

1. **Same-tier model migration: $5,330 / month (exact).** `claude-opus-4-1` → `claude-opus-5-5` is $3,270 of that, after multiplying tokens by 1.30 for Claude's newer tokenizer. If you quote the list-price ratio and skip the tokenizer, you overstate the saving. The number needs no prompt log: it follows from the price table.
2. **Prompt caching: $4,265 / month (measured).** Replay the request log with each model's minimum cacheable prefix and cache TTL. Most of the input is a stable system prompt plus tools; the user turn sits at the end. Cache hit on aggregate data was already 29–34 % on two OpenAI models and **0 %** on every Anthropic model.
3. **Batch API: $555 / month (measured).** The nightly ticket-summary job is visible from the hourly shape: almost all of its traffic sits in two night hours. 50 % off list for that slice.

Routing, output trimming and duplicate calls add smaller lines. They are stacked **multiplicatively**, so you cannot add the table and call it the invoice.

## What people get wrong

**Gateways are not this.** LiteLLM / Helicone / TrueFoundry will show you the $19k. They will not rewrite the prompt so the cache breakpoint sits after the stable prefix, will not put the nightly job on Batch, and will not prove that `opus-5-5` still extracts clause 8.2. The invoice is the proof of saving; an eval set is the proof of quality.

**Input is most of the bill.** On Acme, uncached input is 66 % of spend, output 32 %, cache 3 %. Caching and migration hit the 66 %. Output trimming is a 10 % scenario on the 32 % until you have logs.

**A 100-query eval set is small on purpose.** Acme's sample gate is 100 items with exact-match and required-phrase checks. Baseline (current models) **92 %**, candidate (the migrations above) **94 %**, no regressions. The scorer does not call a model; you bring the outputs. If the candidate drops more than 2 percentage points, that lever does not ship.

## Run it on your own export

Admin key stays with you. The `fetch` command only hits usage and cost report endpoints.

```bash
OPENAI_ADMIN_KEY=sk-admin-... uv run llm-cost-teardown fetch openai --days 30
uv run llm-cost-teardown analyze data/private/*.json --report data/private/report.md
```

Aggregate JSON has no prompts. Request logs are optional and can be fingerprinted (HMAC of prefix blocks, salt thrown away) before they leave the machine.

If annual base saving is under about $6k, the $1,900 audit is not worth it; the report will say so.
